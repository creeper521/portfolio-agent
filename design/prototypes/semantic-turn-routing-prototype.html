SQL 审计项目的实现方案

这是一个面向数据库访问层的 SQL 审计平台，核心是用规则引擎对应用层生成的 SQL 做静态校验和风险拦截。

作品集

项目分三层：规则引擎负责解析 SQL 文本并匹配预置规则（如全表更新、无 WHERE 条件的删除）；拦截层在数据访问层之前介入，命中规则的 SQL 会被记录并按配置放行或阻断；审计层把每次校验结果写入审计表，支持按时间、规则、来源应用检索。规则以 YAML 描述，便于运维在不发版的情况下增补。作品集事实

两个项目的定位差异

SQL 审计偏「质量保障」——在写入路径上拦截风险；ABTest 偏「数据驱动」——在读取路径上支撑决策。前者强调规则引擎与拦截 correctness，后者强调分流均匀性与统计正确性。技术栈有重叠（都涉及数据访问层），但核心问题域不同。作品集事实
