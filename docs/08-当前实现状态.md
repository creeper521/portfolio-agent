## 已实现能力

### 公开作品集

- Vue 前端提供概览、Project、Case、时间线、证据中心与 Agent 工作台；
- Project/Case 公开主体显式且互斥，未知主体失败关闭；
- 公开内容由随包 Bundle 提供，也可从已激活的 PostgreSQL 公开投影读取；
- Case 到 Agent 的交接不把问题写入 URL 或浏览器持久存储；
- 公开内容、错误响应和 Agent 响应遵守脱敏与禁止缓存边界。

### Agent Turn

- 唯一生命周期执行 claim、Goal 解析、Plan 编译、能力执行、公开投影和一次性 settlement；
- 支持作品集解释、比较、推荐、通用知识、跨域综合、安全社交输入与 typed Clarification；
- 相同 `requestId` 支持幂等重放；主动取消与 deadline 采用一次性终局，迟到结果不得提交；
- 推荐未指定数量时使用安全默认值，合法有界数量直接执行，不因未点名候选而强制澄清；
- Clarification 保存最小 typed blocked Goal，不持久化原问题；Challenge 一次消费，同字段不得重复澄清；
- Goal Interpretation 与 General Knowledge 的固定 system prompt 随 JAR 发布并在启动时无条件校验；模型生成文案约束为简体中文，通用解释按 CONCISE/STANDARD/DETAILED 选择 2/4—6/8—12 句，并只接受按顺序出现的一条“概念”和一条“机制”；
- STANDARD 自由文本只接受 AI 提出的 closed SemanticRoute，后端验证 Goal、公开主体、数量、约束与候选范围；原推荐/数量/比较/约束/指代 NLP fallback 已物理删除，模型关闭时自由文本明确不可用；
- Recommendation item 携带后端生成的 ENTER_RESULT action；ProjectDiscussionContext、Conversation active pointer 与 V4 State 是当前项目焦点的唯一权威，CONTINUE 已闭合为 ENTER_RESULT、ROUTE_IN_CONTEXT、EXIT_CONTEXT、REENTER_SUBJECT；
- 当前项目焦点支持卡片进入、受限候选切换、显式退出、过期重建与刷新恢复；页面只恢复 typed focus，不恢复聊天消息，handle 与 resultItemId 不进入 URL 或浏览器持久化；
- 前端 pending、failure、draft 与 notice 按本地 session 隔离；同标签页并发、失败重试、同 requestId replay 与 active cancel 已通过联合 Exit Gate。

### 生产保护

- 每来源速率与并发限制、单实例 Active Turn 上限和单 Turn 任务并行上限均有独立边界；
- Turn 使用覆盖 Goal、Planning、Execution、Projection 与 Settlement 的 absolute deadline；各子操作受自身上限和剩余预算共同约束；
- `429 RATE_LIMITED` 同时返回 `Retry-After` Header 与 `retryAfterSeconds`；
- 来源地址只做进程内匿名 HMAC，不保存原始地址；
- 外部模型无自动重试和跨 Provider 重发，完整响应体也受 operation timeout 约束。

### 短期状态

- `POSTGRESQL` 是标准本地与生产模式；`IN_MEMORY` 用于快速开发和测试；`DISABLED` 是只读浏览模式；
- Context schema 固定为 `agent_context`，由 Flyway 管理；
- Challenge 使用 5 分钟 absolute TTL；Conversation、Continuation Context、Replay 与终局记录使用 30 分钟 absolute TTL，读取不续期；
- Token 与 payload 分别加密，当前密钥与 previous-key 窗口受配置约束；
- 浏览器仅在当前标签页 `sessionStorage` 保存一个 ResumeToken，不保存问题、回答或会话历史。

## 默认配置

- `local` Profile 默认使用 PostgreSQL Agent State，启动器只检查数据库 readiness；
- `prod` Profile 强制使用 PostgreSQL，配置不完整时失败关闭；
- 模型操作、本地检索、公开数据库读取、治理导入和前端诊断按各自开关显式启用；
- 普通本地开发不要求 Provider Secret，真实模型只在策略审批和显式启用后运行。

当前预算基线为：Turn 20 秒，其中预留 2 秒 settlement；Goal Interpretation、General Knowledge、Portfolio Expression 与数据库操作分别受 8 秒、10 秒、4 秒和 3 秒上限约束；前端等待 25 秒，lease 为 35 秒。
