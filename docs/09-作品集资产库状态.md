# 作品集资产库状态
<!-- DOCUMENT_STATUS: CURRENT_AUTHORITY -->

> **核对日期：** 2026-08-19
> **定位：** 当前公开资产治理状态；精确运行快照只见 [当前实现状态](08-当前实现状态.md) 的受检区块。

## 当前状态

仓库已包含一份经人工 Approval 绑定、可由后端严格加载的公开 Bundle。Project、Case、Claim、Evidence、Claim–Evidence 关联、TimelineEvent、QuestionPreset 与检索派生物通过同一 release 边界发布，不能拆开激活或回滚。

公开运行时只读取随包发布目录或已激活的公开数据库投影。Bundle manifest 是版本与数量的唯一机器事实；本文不维护第二份数字。

## 资产治理边界

- 私有资产登记、原始日报、Markdown 源文档和审核工作区不进入公网制品；
- `EXCLUDE`、未批准、证据不足或贡献边界不清的资产保持私有；
- 只有 `APPROVED` Evidence 可进入公开响应；
- Claim 与 Evidence 的支持关系通过显式关联保存，不能从文本相似度推断；
- Project、Case 与 Evidence 的稳定 ID 在发布前完成引用校验；
- 候选包只携带 canonical public payload，派生索引由受控发布端生成；
- 内容变化必须生成新的 release，不能原地覆盖 active 数据。

## 运行方式

默认运行路径读取后端随包 Bundle。公开 PostgreSQL 是可选投影：导入只创建不可变 release，激活需要单独确认；基础设施故障的降级不能绕过 Bundle 校验或 Approval。

治理 PostgreSQL 与公开 PostgreSQL 使用不同数据库、账号和权限。治理导入只允许从显式指定的本地根目录运行，默认 dry-run；它不是应用启动的一部分。

## 当前限制

- 当前资产状态只代表已审核公开材料，不代表相关系统仍在生产运行；
- 性能、业务效果和个人贡献只能按公开 Claim 与 Evidence 表述；
- 新增资产必须重新经历扫描、脱敏、审核、Approval、构建、校验和发布；
- 当前尚未完成生产部署与线上数据验收。
