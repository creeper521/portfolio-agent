什么是乐观锁

乐观锁是一种并发控制策略：它在读取时不加锁，而是在提交更新时再校验数据自读取后是否被改动，通常依赖版本号或时间戳。它假设冲突较少，适合读多写少的场景。

项目 A 如何使用乐观锁

项目 A 在订单服务的更新接口上采用版本号乐观锁：每条记录携带 version 字段，更新时以 WHERE id = ? AND version = ? 匹配并自增；匹配失败则返回冲突，由上层重试。
